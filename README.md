# CT-Dreamer

Rollout in a continuous-time world model.

CT-Dreamer is a continuous-time Dreamer project based on [R2-Dreamer](https://github.com/NM512/r2dreamer) and inspired by [CFO](https://github.com/shannon-hou/CFO_official).

## Installation

Using a virtual environment managed by [uv](https://docs.astral.sh/uv/) is recommended.

```bash
uv venv --python 3.11
source .venv/bin/activate
uv pip install -e ".[dmc,metaworld]"
```
